# Penguin Mod (Fabric)

Minecraft Java Edition **1.21.11**, Fabric Loader, Java 21.

## Build

Run from this directory:

```sh
gradle build --no-daemon
```

The built mod jar will be in `build/libs/`.

## Features

- Penguins spawn in biomes tagged by `data/penguinmod/tags/worldgen/biome/spawns_penguins.json`.
- Penguins can be tempted and bred with fish.
- Custom Blockbench-based model, texture, waddling animation, and spawn egg.
